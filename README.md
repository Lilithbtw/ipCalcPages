# IPv4 Check App

A simple web application that provides IPv4-related tool via a web interface.

## Features

- Web-based IPv4 tool
- Simple UI with `index.html` and `calc.html
  
## Prerequisites
- No prerequisites just just standard Web Server (Apache/Nginx)
## Installation (Local)

1. **Clone the repository**
```bash
git clone https://github.com/lilithbtw/ipCalcPages.git
cd ipCalcPages
```

4. **Run the Application**

```bash
mv * /var/www/html
```

Then visit http://localhost in your browser.

To access the website via the internet just go to calc.secunda.casa
